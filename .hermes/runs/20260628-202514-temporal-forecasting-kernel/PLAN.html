PLAN — Temporal Forecasting Kernel

READY_FOR_REVIEW

Goal

Implement the smallest useful Temporal Forecasting Kernel slice: forecast contracts, as-of evidence dossiers, deterministic forecast protocol, immutable JSON ledger, resolution, scoring, and CLI wiring.

Implementation Principles

  • TDD first for each component.
  • Deterministic kernel first; LLM protocol seam only if needed.
  • Use JSON repository for MVP forecast ledger, behind a service abstraction.
  • Do not modify original checkout; work only in this worktree.
  • Do not claim calibrated performance; report low-sample warnings.

Task 2 — As-of evidence compiler and data-source adapter

ObjectiveCompile leakage-safe evidence dossiers from current graph store data using explicit record-time and valid-time rules.
FilesCreate src/engram/services/as_of_evidence.py; test tests/unit/test_as_of_evidence.py. Add a service-level GraphEvidenceAdapter protocol in this file for MVP rather than vague helper methods.
Steps
  1. Write tests using MemoryStore, entities, facts, and relationships with dates before/after forecast_as_of.
  2. Define GraphEvidenceAdapter methods matching the design: get_facts_as_of, get_relationships_as_of, and get_target_evidence_as_of. Implement MemoryGraphEvidenceAdapter first; Neo4j adapter can be deferred unless needed by tests.
  3. Adapter traversal must include direct target facts, outbound and inbound relationships involving the target, and one-hop related entity facts only when both relationship and related fact are known as-of.
  4. Test future-recorded facts are excluded even if valid time is before as-of.
  5. Test metadata.source_ingested_at > forecast_as_of exclusion separately from recorded_from.
  6. Test resolution evidence markers are excluded: evidence_role=resolution_evidence or matching resolution_for_question_id.
  7. Test post-hoc derived evidence is excluded via derived_after > forecast_as_of.
  8. Test supersession algorithm: scan replacement facts where new_fact.supersedes_fact_id == old_fact.id; if replacement recorded_from <= forecast_as_of, old packet is superseded_before_as_of; if replacement recorded_from > forecast_as_of, old packet remains current_as_of_later_superseded; do not require store-level recorded_to mutation in MVP.
  9. Implement AsOfEvidenceCompiler with deterministic ordering and excluded_counts.
  10. Run uv run pytest tests/unit/test_as_of_evidence.py -q.
DoneLeakage and supersession tests pass before any forecast-quality tests are written. Data access is explicit via the adapter contract.
