Demo Proof: Forecast Kernel Works End-to-End

Status: PASS

This proof is not just unit tests. It creates a fresh forecast ledger, compiles evidence, creates a forecast run, resolves it, scores it, and verifies leakage rejection using the actual installed CLI commands.

Scenario

  • Question: Will Alice renew by the end of the 30 day horizon?
  • Forecast as-of: 2026-01-15T00:00:00+00:00
  • Branches: renew, churn
  • Evidence: two records known before as-of, supporting renewal / opposing churn.
  • Resolution: renew.
  • Negative control: future-recorded evidence is intentionally supplied and must be rejected.

Commands exercised

uv run engram forecast-question-create ...
uv run engram forecast-dossier-compile ...
uv run engram forecast-run-create ...
uv run engram forecast-resolve-create ...
uv run engram forecast-score-report ...
uv run engram forecast-dossier-compile ...future_evidence.json...

What this proves

  • The CLI commands compose into a full user-visible workflow.
  • The forecast run produces a normalized probability distribution.
  • Relevant evidence changes the top branch to renew.
  • The immutable ledger stores question, run, resolution, and score artifacts.
  • The scorer computes Brier/log score and top-1 correctness from a real resolution.
  • The leakage guard rejects future-recorded evidence instead of silently using it.
