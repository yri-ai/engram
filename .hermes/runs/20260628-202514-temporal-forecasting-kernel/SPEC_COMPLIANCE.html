Spec Compliance

Status: PASS

Requirements satisfied

  • As-of belief formation: implemented forecast questions with forecast_as_of, horizons, branches, resolution criteria, and explicit evidence dossiers.
  • Leakage control: as-of compiler filters future-recorded facts, source-ingested-after-as-of facts, resolution evidence, and post-hoc derived evidence; JSON dossier CLI applies equivalent validation for MVP imports.
  • Immutable forecast ledger: forecast runs are append-only; duplicate run IDs are rejected; active questions cannot be overwritten after activation.
  • Scoreable probability distributions: runs require branch-complete, finite, bounded probabilities summing to 1.0, with a valid max-probability top branch.
  • Resolution and scoring: repository stores resolutions and scores; Brier, log score, top-1/top-k, and calibration reports are implemented.
  • CLI access: added question, dossier, run, resolution, and score report commands.
  • Documentation: README section and architecture plan document added.

Intentional MVP scope

  • Forecast protocol is deterministic baseline, not LLM/ML forecasting yet.
  • CLI dossier compiler supports JSON evidence for first workflow; Neo4j-backed compiler exists as a service seam for later CLI/API wiring.
  • Calibration report warns on low sample counts and is not positioned as statistically stable below threshold.
